# stashie

A calm, modular toolkit for capturing and processing AI-generated files without breaking your flow.

> From single-file saves to full-featured automation, stashie helps you offload ChatGPT output smoothly into your local workflow.

## Overview

Stashie is a layered system for working with artifacts generated by ChatGPT or other tools. The goal is to reduce context-switching and support fast, flow-friendly dev workflows, especially on macOS.

This repository contains:
- `shell/`: CLI tools for interactive file retrieval (see `stashie-func`)
- `docs/stashie-onion-layers.md`: a working vision document for how stashie evolves
- `examples/`, `test/`, and `.stashie.rc.example`: reference usage and customization

For an overview of the broader architecture and priorities, see  
👉 `docs/stashie-onion-layers.md`
