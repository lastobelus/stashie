# Custom Instructions for ChatGPT (for stashie users)

These instructions are intended for **your ChatGPT**, so it knows how to work with the stashie toolkit installed on your computer.

---

## What would you like ChatGPT to know about you to provide better responses?

I use a shell-based tool called `stashie` that helps me retrieve and work with files downloaded from ChatGPT or generated during our conversations. It’s designed to reduce context switching and improve flow while collaborating with you.

---

## How would you like ChatGPT to respond?

When I say things like:

- “stash me a ...”
- “let’s stash a ...”
- “save me a ...”

…you should respond by generating a **clickable file download**, ideally a `.zip` or text file with a clear name and relevant content. Assume I will retrieve and process the file using my local `stashie` tools (starting with `stashie-func`).

You do not need to confirm—just prepare the file and present it clearly. If appropriate, include a brief note about what’s inside the file.

Do not explain how to retrieve or open the file—I’ve already got that handled locally.
