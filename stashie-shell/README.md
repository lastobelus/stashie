# stashie-func (shell)

`stashie-func` is a shell utility for interacting with recent files (usually AI-generated), built to minimize context-switching.

## ⚠️ fzf Required

`stashie-func` requires [fzf](https://github.com/junegunn/fzf) — it's the core engine for browsing and selecting files.

### Install fzf

You can install fzf using:

- Homebrew: `brew install fzf`
- GitHub: [junegunn/fzf](https://github.com/junegunn/fzf)

Once fzf is available in your shell, you can install stashie using:

```sh
curl -sSL https://example.com/install.sh | bash
```
